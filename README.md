# Сайт кофейни «Большой кофе»

Одностраничный сайт сети «Большой кофе» (Волжский и Волгоград).

**Live:** https://iluuua.github.io/big-coffee-site/

Деплой: `git push` в `main` → GitHub Pages собирает автоматически.
Стек: статичный HTML + CSS + минимальный JS, без сборки.

## Точки

**Волжский, ул. Мира, 112** (31-й микрорайон) — основная.
Данные с Яндекс Карт (07.08.2026), карточка `24043248419`:

- Рейтинг 5,0 · 460 оценок · 231 отзыв · 120 фото
- Ежедневно 07:00–23:00, завтраки с 7:00
- +7 (937) 098-11-01
- Координаты 48.759878, 44.815889; индекс 404118
- Ориентир: храм Серафима Саровского, 156 м
- Кофейня, кондитерская, доставка, навынос, парковка, туалет (в т.ч. для
  маломобильных), оплата картой/QR/наличными, можно с собакой, подарочные сертификаты

Адрес уточнён: Яндекс даёт «31-й микрорайон» без улицы; обратное геокодирование
координат карточки даёт ул. Мира, 112, а храм Серафима Саровского оказывается
в 156 м — ровно как указано в карточке.

**Волгоград, проспект имени В. И. Ленина, 92** — небольшая точка.
На Яндекс Картах отсутствует, адрес получен от владельца.
Часы работы и телефон пока не подтверждены — на сайте помечены как уточняемые.

## Меню

Перенесено с фотографии печатного меню сети (есть в галерее точки в Волжском).
Меню доставки в Яндекс Еде дороже примерно на 15–20% — на сайте цены кофейни.
Актуальность цен подтверждает владелец.
